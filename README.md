# Skills IA que j'utilise en marketing

Par Selena Zennaf, étudiante en Master Marketing.

Ce dépôt documente les skills (fichiers d'instructions pour l'IA) que j'ai
testés pour des tâches marketing : ce qu'ils font, comment je les ai
vérifiés et mon avis.

## Ma méthode de vérification

1. Je lis le SKILL.md en entier avant de l'installer.
2. Je vérifie l'absence de scripts, d'appels externes et d'instructions suspectes.
3. Je teste sur des données publiques ou fictives.
4. Je relis et corrige les résultats de l'IA.
